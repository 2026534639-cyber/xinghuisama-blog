# 更新日志

> 记录 2026-08-19 之后的新功能与修复。

## 2026-08-20 · 访客分析系统（重点）

### 博客（fall07.top）
- **城市归属显示**：访客上报时用 Cloudflare 原生地理信息解析 IP 所在省/市（不再依赖被 403/限流的第三方 IP 库），内置全国省市 + 常见国家中文翻译表，看板显示「广东·广州」格式；省=市时只显示一个
- **访客上报增强**：记录访客编号、设备类型（电脑/手机/平板）、手机型号、WiFi / 数据网络
- **存储升级**：接入 Cloudflare KV（visit-stats 命名空间），按天存储，查询支持 今天/一周/一月/一年
- **阅读量去重**：同标签页刷新不再重复计数（不蒜子），新访客/新标签页正常计数
- 测试性调试端点已清理

### 控制台（星辉云端）
- **看板访客面板**：访问次数 / 独立访客 / 设备 / 网络统计卡片 + 城市分布 + 手机型号分布 + 最近 100 条明细（设备徽章、访客编号、IP·城市、路径、时间）
- **自愈看门狗**：每 15 秒探测前后端端口，前端/后端崩溃自动重启并刷新窗口（60 秒内最多 3 次，防死循环）——窗口白屏/卡死不再需要手动处理
- 访客编号权限管理页：查看访客编号、授/收隐藏文章权限

## 2026-08-19 · 安全修复 + 数据看板 + 性能优化

### 博客（fall07.top）
- **隐藏文章**：仅授权访客可见（列表/RSS 过滤 + 文章页守卫），编辑器一键开关
- **访客编号系统**：发号 + 权限徽章（博客页头像旁）
- **评论区迁移**：Vercel 托管（twikoo），替换被封的 Netlify 服务
- **性能**：移除 Live2D 看板娘（-11MB）、three.js 拆出主包按需加载、正文图片懒加载
- **浏览统计**：接入不蒜子（文章阅读量 + 首页全站访客/浏览量）
- **分享与订阅**：文章 OG 分享卡片 + RSS 订阅源（feed.xml）
- **音乐页**：歌单分组（华语/DJ嗨曲/欧美日韩），可折叠 + 搜索平铺；新增 16 首自定义音乐及歌词
- **修复一批**：死引用/死代码清理、LRC 解析、懒加载注入、feed 排序、备案链接、返回按钮

### 控制台（星辉云端）
- **数据看板**：内容统计 + 最近发布 + 播放列表
- **安全加固**：CORS 白名单（恶意来源拒绝）、图床 token 剥离 secrets（对外不泄露）、按类型删除草稿、slug 404 处理、随机歌单
- **健壮性**：前后端端口固定 5155/5156、启动残留进程清理、源码模式不再被 build 挤掉、日志落盘（logs/）
- 同步博客优化（懒加载/three.js）
